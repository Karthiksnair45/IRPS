IRPS — Interactive Rock Paper Scissors
A gesture-controlled Rock Paper Scissors game built with Python. Uses your webcam to detect hand gestures in real time — no keyboard needed.
Built with OpenCV, MediaPipe, and Tkinter as a final year BCA project.
Setup
bashpip install opencv-python mediapipe pillow
py game.py

Requires hand_landmarker.task in the project folder. Download from Google's MediaPipe model repository.
